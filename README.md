# GARAGE COSMOHACK26

Веб-приложение для моделирования спутниковой группировки: трёхмерная модель
Земли, орбитальные плоскости, спутники, наземные станции и маршруты связи.
Пользователь может создавать конфигурации вручную или загружать JSON,
моделировать отказы, рассчитывать метрики, сравнивать сценарии и подбирать
параметры развёртывания группировки.

## Основные технологии

| Слой | Технологии | Назначение |
| --- | --- | --- |
| Интерфейс | React 19, TypeScript | Компоненты интерфейса и управление состоянием |
| 3D-визуализация | Three.js, WebGL | Земля, орбиты, спутники и маршруты связи |
| Стили и иконки | Tailwind CSS 4, Lucide React | Оформление интерфейса |
| Сборка frontend | Vite 6, npm | Сервер разработки и production-сборка |
| Backend | Python, FastAPI, Uvicorn | HTTP API, WebSocket-каналы и запуск сервера |
| Расчёты | NumPy, Python | Геометрия орбит, маршрутизация, метрики и оптимизация |
| Валидация | Pydantic, python-multipart | Проверка запросов и приём JSON-файлов |
| Хранение проектов | localStorage | Библиотека конфигураций в браузере |
| Python-зависимости | uv | Установка зависимостей и виртуальное окружение |

Frontend передаёт активную конфигурацию backend через REST API. Backend
рассчитывает положения спутников и маршруты, а React отображает результаты
в Three.js-сцене. Текущий клиент опрашивает телеметрию и маршруты с интервалом,
зависящим от шага сценария и скорости симуляции. Backend также предоставляет
WebSocket-каналы. Метрики и сравнение возвращаются как JSON или CSV,
результаты оптимизации поступают потоком NDJSON.

## Локальный запуск для разработки

Потребуются Python 3.12 или новее, установленный `uv`, Node.js 22 и npm.
Первичная установка зависимостей требует доступа к PyPI и npm registry.
Все команды ниже выполняются из корня клонированного репозитория,
если явно не указан переход в другую папку.

### 1. Установить Python-зависимости

```bash
uv sync
```

### 2. Запустить backend

В первом терминале:

```bash
cd src/garage_cosmohack26/back
uv run python -m uvicorn main:app --port 8000 --reload
```

Backend доступен по адресу <http://localhost:8000>, документация API —
<http://localhost:8000/docs>. Флаг `--reload` перезапускает сервер при изменении
Python-кода.

### 3. Запустить frontend

Во втором терминале, начиная из корня репозитория:

```bash
cd src/garage_cosmohack26/front
npm install && npm run dev
```

Открыть приложение: <http://localhost:3000>.

Оба терминала должны оставаться запущенными. Vite перенаправляет запросы
`/api` и `/ws` на backend по адресу `127.0.0.1:8000`. Для остановки сервера
используйте `Ctrl+C` в соответствующем терминале.

## Локальный запуск собранного приложения

Этот режим позволяет посмотреть приложение с production-сборкой:
FastAPI раздаёт frontend и API через один порт, без сервера разработки Vite.

Сначала установить зависимости и собрать frontend:

```bash
uv sync
cd src/garage_cosmohack26/front
npm ci
npm run build
```

Затем в терминале из корня репозитория запустить backend:

```bash
uv run python -m uvicorn main:app \
  --app-dir src/garage_cosmohack26/back \
  --host 127.0.0.1 \
  --port 8000 \
  --workers 1
```

Открыть приложение: <http://localhost:8000>.

Сборка должна завершиться **до** запуска backend. При изменении frontend
повторите `npm run build` и перезапустите backend. Один worker необходим,
поскольку активная симуляция хранится в памяти процесса и используется
совместно всеми подключёнными клиентами.

## Готовые конфигурации для проверки

Тестовые JSON-файлы уже включены в репозиторий и находятся в папке
[`src/garage_cosmohack26/back/configs`](src/garage_cosmohack26/back/configs).
После клонирования проекта скачивать их отдельно не нужно.

| Файл | Сценарий |
| --- | --- |
| [01_full_constellation.json](src/garage_cosmohack26/back/configs/01_full_constellation.json) | Полная группировка, третий этап развёртывания |
| [02_first_launch.json](src/garage_cosmohack26/back/configs/02_first_launch.json) | Первая очередь запуска |
| [03_satellite_outages.json](src/garage_cosmohack26/back/configs/03_satellite_outages.json) | Недоступность десяти спутников |
| [04_link_range.json](src/garage_cosmohack26/back/configs/04_link_range.json) | Ограниченная дальность межспутниковой связи: 2000 км |
| [02_first_launch_stage1_opt.json](src/garage_cosmohack26/back/configs/02_first_launch_stage1_opt.json) | Сохранённый результат оптимизации первой очереди |

Чтобы открыть сценарий:

1. Запустите приложение и откройте меню «Проект» в верхней панели.
2. Выберите «Создать новый проект».
3. В верхней части окна загрузите JSON-файл из папки `back/configs`.
4. Проверьте или измените параметры и сохраните проект.

Для первой проверки используйте `01_full_constellation.json`. Остальные
файлы позволяют проверить этапы запуска, отказы, ограничения связи и
сравнение конфигураций. Во всех этих примерах горизонт составляет 86400
секунд, а шаг — 120 секунд. Целевая доступность в полном сценарии равна
10%, в остальных — 90%; учитывайте это при сравнении выполнения цели.

Библиотека проектов в текущем frontend читается из localStorage, поэтому
файлы на диске не появляются в меню автоматически: их нужно загрузить
через интерфейс.

## Полезные команды

В папке `src/garage_cosmohack26/front`:

```bash
npm run lint   # Проверка TypeScript (tsc --noEmit)
npm run build  # Сборка frontend в dist/
```

Конфигурации используют JSON-формат `cosmo-A-1.0`. Сохранённые через frontend
проекты привязаны к браузеру и адресу приложения: `localhost:3000` и
`localhost:8000` имеют разные хранилища localStorage.

## Если запуск не удаётся

- `Temporary failure in name resolution`: система не может разрешить адрес
  PyPI или npm registry. Проверьте подключение к интернету и DNS.
- `uvicorn` не найден: сначала дождитесь успешного завершения `uv sync`.
- `vite` или `tsc` не найден: выполните `npm install` в папке frontend.
- В development-режиме открывайте порт `3000`; порт `8000` раздаёт только
  ранее собранный `dist`, который может быть устаревшим или отсутствовать.

Если зависимости уже есть в локальном кеше, можно установить их без сети:

```bash
uv sync --offline --python 3.13
cd src/garage_cosmohack26/front
npm ci --offline
```

Для офлайн-установки нужны локально установленный Python указанной версии
и кеш всех совместимых пакетов. Используйте прямой запуск через Uvicorn,
показанный выше: консольный entrypoint `garage-cosmohack26` в текущем
`pyproject.toml` требует отдельного исправления.
